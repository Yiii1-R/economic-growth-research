# 各国历史经济增长影响因素研究

本项目拟构建跨国历史面板，研究各国经济增长率的长期差异及其影响因素。

当前阶段是研究范围与数据收集设计，尚未开始正式数据采集或计量分析。

## 当前文件

- `docs/数据收集计划.md`：研究口径、数据源分层、采集流程和质量标准
- `docs/数据采集执行计划.md`：由 Codex 执行的分波次采集、数据构造和验收计划
- `metadata/数据源登记表.csv`：候选数据源及下载状态
- `metadata/变量字典.csv`：候选变量、定义和数据来源
- `metadata/国家代码对照表.csv`：历史国体与现代 ISO3 代码的映射模板
- `data/raw/`：原始数据，只读保存
- `data/processed/`：清洗和构造后的分析数据
- `scripts/`：下载、清洗和检查脚本
- `reports/`：覆盖率和数据质量报告
