# 数据采集执行计划

版本：1.0（执行草案）  
执行人：Codex  
执行起点：2026-10-25  
目标：先独立完成 15 国试点数据，再决定是否扩展到全部国家

## 1. 我的执行原则

这份计划不是在等待更多研究设计后启动，而是由我先采用一组明确、可修改的默认口径开展试点。用户后续若调整研究问题，我只需要替换相应数据层，不重做全部采集。

我的执行原则是：

1. 先验证数据是否支持问题，再扩大样本。
2. 先用小样本跑通完整流程，再下载全量数据。
3. 原始数据只读保存，清洗结果不得覆盖原始文件。
4. 每个数据源保留自己的单位、价格基准和变量定义。
5. 不把 Maddison、PWT 和 WDI 拼成一条基线序列。
6. 不默认插值，不把缺失值当作零。
7. 每次合并后检查主键、国家覆盖和样本量变化。
8. 所有判断写入决策记录，保证以后可以解释为什么这样做。

## 3. 两个分析样本

单独采集全部数据后，我会构造两个明确样本，而不是强行让所有变量覆盖 1820—2019。

### 3.1 历史长期样本

时期：1820—1949 年，必要时延伸到 2019 年。  
主要变量：

- Maddison 人均实际 GDP
- 期初收入水平
- 人口及其增长
- 可用的历史制度指标
- 地理不变量

这个样本的核心限制是历史人力资本、贸易和冲突指标覆盖有限。若变量覆盖过低，我只保留确实可比较的部分，不用现代数据反推历史值。

### 3.2 现代完整样本

时期：1950—2019 年。  
主要变量：

- Maddison 和 PWT 人均 GDP
- 投资份额
- 人口增长
- 人力资本或受教育年限
- 贸易开放度
- 民主程度和行政约束
- 武装冲突
- 地理和地区变量

这是首轮最适合承载完整 P0 变量和计量分析的样本。

## 4. 采集波次

我按“结果变量优先、解释变量随后、质量检查贯穿”的顺序执行。

### 第一波：结果变量

目标：确认试点国家是否有足够的历史产出数据。

| 顺序 | 来源 | 目标字段 | 主要用途 |
|---|---|---|---|
| 1 | SRC-001 Maddison Project Database | `gdppc`、`pop` | 历史基线 |
| 2 | SRC-002 Penn World Table | 实际 GDP、人口 | 1950 年后稳健性 |
| 3 | SRC-003 World Development Indicators | 人均 GDP 或人均 GNI | 外部核验 |

执行动作：

1. 从官方发布页选择最新稳定版本。
2. 下载机器可读格式，优先 CSV、Excel 或 Stata。
3. 在 `data/raw/SRC-XXX/<version>/` 保存原始文件。
4. 写入该目录的 `SOURCE.txt`，记录 URL、版本、访问日期、许可和字段说明位置。
5. 生成 `checksums.sha256`，避免后续文件被无意替换。
6. 读取字段名、主键、年份范围和国家范围。
7. 构造 15 国人均 GDP 年度试点表。
8. 报告 1820、1870、1913、1950、1980、2000 和 2019 年的覆盖情况。

第一波通过条件：

- 15 国都能在现代 ISO3 中找到对应实体。
- Maddison 数据能支持至少一个 20 年历史窗口。
- PWT 数据能支持 1950 年后的 5 年窗口。
- Maddison、PWT、WDI 没有在同一个基线变量中混合。
- 所有结果变量能追溯到具体来源文件和原始字段。

### 第二波：人口、投资、人力资本和贸易

目标：建立历史样本的基本条件和现代样本的核心解释变量。

| 变量 | 主来源 | 备选或核验来源 | 使用时点 |
|---|---|---|---|
| 人口增长 | Maddison、UN WPP | WDI | 增长窗口起点以前 |
| 投资份额 | PWT | WDI 资本形成占比 | 窗口起点或前期 |
| 人力资本指数 | PWT | 无 | 1950 年后 |
| 平均受教育年限 | Barro-Lee | Wittgenstein Centre | 窗口起点或前期 |
| 贸易开放度 | PWT | WDI 贸易占 GDP 比例 | 窗口起点或前期 |

执行规则：

- 年度变量优先取窗口起点年份的值。
- 起点缺失时，只允许向前寻找 3 年内最近值，并记录匹配年份。
- 不使用窗口结束后的值，不用未来值向前填充。
- Barro-Lee 的五年数据取不晚于窗口起点的最近一期。
- PWT 的 GDP 增长核验优先使用固定国家价格的实际 GDP 除以人口。
- PWT 和 WDI 的贸易开放度定义不同，分别保留为不同变量。

第二波通过条件：

- 每个变量有明确单位、时点和缺失标记。
- 5 年窗口的核心解释变量覆盖率可以量化。
- 没有任何解释变量使用增长窗口结束后的信息。
- 每个匹配上的观测记录其原始年份和方法。

### 第三波：制度和冲突

目标：加入长期增长研究最常见、但口径差异也最大的制度与冲突变量。

| 概念 | 主指标 | 稳健性指标 | 处理原则 |
|---|---|---|---|
| 民主程度 | V-Dem 连续民主指标 | Polity5 政体指标 | 分开保存，不混成一个变量 |
| 行政约束 | Polity5 行政约束 | V-Dem 对应指标 | 分类尺度需保留原始值 |
| 冲突发生 | UCDP/PRIO 冲突事件 | 后续历史冲突来源 | 仅覆盖有可靠数据的年份 |
| 冲突强度 | UCDP 强度或死亡人数 | 无 | 不把缺失当作无冲突 |

执行规则：

- V-Dem 作为连续制度指标的主来源。
- Polity5 作为历史稳健性检验，不直接替换 V-Dem。
- 政体分类变量保留原始取值和缺失代码。
- UCDP 主要支持 1946 年后分析。
- 历史冲突数据覆盖不足时如实保留缺失，不根据现代国家冲突率推算。

第三波通过条件：

- 制度变量的单元、分类和缺失代码有代码本记录。
- 同一概念的主指标与稳健性指标不覆盖进同一列。
- 冲突变量能区分“没有冲突”“未观测到冲突”和“数据缺失”。

### 第四波：地理和国家分类

目标：补齐时不变变量，并为样本筛选和描述统计提供统一分类。

| 来源 | 目标字段 | 用途 |
|---|---|---|
| SRC-010 CEPII GeoDist | 内陆国、纬度、国家代码 | 地理变量 |
| SRC-012 World Bank metadata | ISO3、地区、收入组 | 分类和核验 |
| SRC-011 UN WPP | 人口、年龄结构 | 现代人口核验 |

执行规则：

- 地理变量使用现代国家边界，历史分析中作为近似控制变量。
- 地区和收入组只作为分类变量，不回溯解释 19 世纪收入差异。
- 所有来源国家名都通过代码对照表映射，不直接按字符串合并。

### 第五波：构造面板

目标：生成可复核的年度、5 年和 20 年试点数据。

输出文件：

```text
data/processed/pilot_country_year_v0.1.csv
data/processed/pilot_country_period5_v0.1.csv
data/processed/pilot_country_period20_v0.1.csv
metadata/pilot_country_crosswalk_v0.1.csv
```

年度面板至少包含：

- `country_id`、`iso3`、`year`
- 各来源的人均 GDP 原始值
- 人口及人口增长
- 投资份额
- 人力资本或受教育年限
- 贸易开放度
- 民主和行政约束指标
- 冲突指标
- 地理和地区变量
- 每个变量的来源、匹配年份和缺失标记

窗口面板至少包含：

- `country_id`、`period_start`、`period_end`、`window_length`
- 年化增长率
- 期初人均 GDP
- 期初或前期解释变量
- 窗口内可用年数
- 结果变量和解释变量的缺失标记

合并规则：

- 主键为 `country_id + year`。
- 合并前后行数必须解释。
- 一对多合并必须先汇总到国家—年份，不允许静默放大样本。
- 使用外连接构造完整时间轴，不使用内连接直接丢掉缺失国家。
- 每次合并写出新增、匹配和未匹配记录数。

### 第六波：质量检查

目标：判断数据能否支撑分析，而不只是确认文件能打开。

必做检查：

1. 主键唯一。
2. 年份范围正确，无重复或非法年份。
3. 国家代码映射完整，无未知实体。
4. 变量类型正确，数值字段没有被误读为字符串。
5. 比例变量、对数变量和增长率取值范围经过检查。
6. 原始异常值保留，但设置质量标记。
7. 各变量在关键年份的国家覆盖数。
8. 各国最长连续可用期和主要断点。
9. Maddison、PWT、WDI 重叠期的水平和增长率差异。
10. 不同来源的人均 GDP 排名是否出现不合理大幅变化。

输出报告：

```text
reports/pilot_coverage_v0.1.md
reports/pilot_source_comparison_v0.1.md
reports/pilot_data_quality_v0.1.md
reports/pilot_decisions_v0.1.md
```

覆盖率报告至少按以下年份切面：

> 1820、1870、1913、1950、1980、2000、2019

### 第七波：试点评审

目标：决定全样本范围和后续变量。

我会在报告中回答：

- 哪些变量真正支持 1820 年以来的长期分析？
- 哪些变量只适合 1950 年后？
- 哪些国家因历史边界或数据缺失需要特殊处理？
- 5 年和 20 年窗口各自损失多少观测？
- Maddison、PWT 和 WDI 的分歧是否影响主要结论所需的精度？
- 哪些 P1 变量值得继续收集？
- 全样本是否需要人口门槛或国家实体规则？

只有完成这次评审后，才进入全样本下载和 `v1.0` 数据冻结。

## 5. 数据源锁定方法

每个来源在下载时都必须完成以下记录：

| 字段 | 要求 |
|---|---|
| 来源编号 | 使用现有 `SRC-XXX` 编号 |
| 数据集名称 | 完整名称，不只写缩写 |
| 版本 | 官方版本号或发布年份 |
| 下载地址 | 官方发布页面或文件地址 |
| 访问日期 | 实际下载日期 |
| 原始文件名 | 保持下载时的文件名 |
| 文件哈希 | SHA-256 |
| 时间覆盖 | 最早和最新有效年份 |
| 国家覆盖 | 实体数量和特殊地区 |
| 关键字段 | 最终采用的原始字段名 |
| 引用与许可 | 官方引用、许可和数据使用说明 |

如果无法确认版本，我不把该文件标为“已采集”，而是标为“待核验”。

## 9. 风险与处理

| 风险 | 处理方式 |
|---|---|
| 官网改版或版本更新 | 记录实际访问日期；锁定下载时版本；不覆盖旧版本 |
| 网络访问受限 | 保存失败记录；使用官方可获得的本地副本；需要联网下载时再请求授权 |
| 历史国家边界不一致 | 通过人工代码映射和历史实体编号处理 |
| 早期变量覆盖过低 | 缩减历史模型变量；不以现代值反推历史 |
| 来源单位不一致 | 保留原始单位；另建标准化变量；记录换算公式 |
| 极端增长和战争冲击 | 保留原值；建立异常标记；分析阶段再决定缩尾 |
| 多来源指标分歧 | 分开报告；不平均成一个无来源的变量 |
| 数据许可限制 | 在登记表中记录许可；不重新分发不允许公开的文件 |
